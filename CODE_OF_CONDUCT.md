# Code of Conduct

## Our Standards

This is a small, opinionated project maintained by a focused team. We welcome respectful bug reports and well-scoped issues.

Unsolicited feature PRs, scope creep, or design debates are generally not accepted. If you're unsure whether something is in scope, open an issue first — saves everyone time.

Be direct. Be respectful. Don't waste people's time.

## Enforcement

Maintainers reserve the right to close issues or PRs that don't fit the project's direction without explanation.

## Contact

Open a GitHub issue.
