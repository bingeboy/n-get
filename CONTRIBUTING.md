# Contributing

This is a solo project. Contributions are welcome but scope is intentional.

## Issues

Bug reports and ideas are welcome. Open an issue.

## Pull requests

Open an issue first and wait for a response before writing any code. Unsolicited PRs will be closed without review.

## Scope

n-get is an AI-native download tool. Features that don't serve agent workflows are out of scope.

## Code of conduct

Be straightforward. No drama.
